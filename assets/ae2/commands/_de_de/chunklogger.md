# chunklogger

**Verwendung:** `/ae2 chunklogger`

Schaltet die Chunk-Protokollierung ein oder aus. Solange sie läuft, schreibt der Server jedes Laden und Entladen eines Chunks ins Log: so findet man, was Chunks geladen hält.
